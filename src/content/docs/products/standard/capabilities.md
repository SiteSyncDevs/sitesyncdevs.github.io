- Connect to a LoRa Network Server (ChirpStack, Actility ThingPark, The Things Stack, Loriot, Multitech Conduit) via MQTT + REST API.
- Create device profiles with decoders (JavaScript or API) and UDTs.
- Onboard devices by manual form or bulk CSV upload.
- Model decoded data as Ignition tags; set Primary and Display values.
- Send downlinks (preconfigured, builder, or ad hoc).
- Diagnose devices with signal, battery, packet-delivery, and status metrics.

See the [Product comparison](/products/enterprise/standard-vs-enterprise/) for how this differs from Enterprise.
