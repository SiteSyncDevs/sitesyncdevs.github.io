SiteSync Standard is a single deployment. It does **not** include:

- **Multi-site structure** — no sites; Enterprise adds site organization.
- **Multiple connections** — Standard supports a single connection.
- **Role separation** — no split between a central admin app and a site-facing Field App.
- **Fleet dashboard** — the enterprise-wide fleet view is Enterprise only.
- **Enterprise-wide device access** and **mobile camera scanning** (Field App).

If you need any of these, see [SiteSync Enterprise](/products/enterprise/overview/).
