## What this means

The app scanned a code but it isn't a supported format, or it didn't scan at all.

## Check these first

1. The code is a [supported format](/use/add-device/scan-qr/#supported-qr-formats) — LoRa Alliance or SiteSync.
2. You're in the **Perspective mobile app** (camera scanning is mobile-only).
3. Lighting and focus — clean the label and steady the camera.

## Resolution

If the format isn't recognized, the app returns everything it read — enter the join keys [manually](/use/add-device/add-manually/).
