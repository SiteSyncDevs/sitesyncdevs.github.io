1. Reproduce the issue and note the exact steps.
2. Assemble a [diagnostic package](/support/collect-diagnostic-package/).
3. [Contact support](/support/contact-support/) with the package, describing expected vs actual behavior and whether it affects one device, one site, or the whole fleet.
