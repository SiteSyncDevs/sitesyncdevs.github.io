SiteSync runs on Ignition, so relevant logs are the **Gateway logs**. In the Gateway web config, open **Status → Diagnostics → Logs** (Logs viewer) to view and export entries around the time of the issue.

:::note[Confirm loggers]
Add the specific SiteSync logger names to filter on (for connections, decoding, provisioning). Confirm with SiteSync Product.
:::
