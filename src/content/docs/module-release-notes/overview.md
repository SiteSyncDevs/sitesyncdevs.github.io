These notes cover the **SiteSync LoRaWAN module** — the Ignition module that ingests uplinks, writes tags, and generates downlinks. The module is versioned **independently of the SiteSync projects** (Standard, Enterprise Management, Field App), so a module upgrade does not necessarily coincide with a project release.

For project/product release notes, see [Release notes](/release-notes/1-0-0/).
