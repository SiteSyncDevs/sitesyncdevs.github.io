## Goal

Get the correct CSV template before adding devices in bulk.

## Steps

1. In the left sidebar, select **Bulk Upload**.
2. At the top of the page, select **Click to download template**.
3. Open the file in a spreadsheet application (Excel, Google Sheets).

:::caution[Don't change the headers]
Always start from the downloaded template. The template contains the required column headers — do not change or delete them. Uploading a CSV with incorrect or missing headers will cause the upload to fail.
:::
