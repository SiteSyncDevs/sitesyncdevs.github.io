A device profile specifies the LoRaWAN **region** (frequency plan) for where the device is deployed — for example `US915` for North America or `EU868` for Europe. Today the region is used primarily for filtering; richer per-region settings are planned.

Common regions include EU868, US915, AU915, and AS923.
