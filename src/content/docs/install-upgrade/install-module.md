Installing the SiteSync module is the same for both editions — the edition is determined by the Perspective projects you import afterward, not by the module.

## Steps

1. Open the Ignition Gateway web configuration page.
2. Go to **Config → Modules** and choose **Install or Upgrade a Module…**.
3. Select the SiteSync `.modl` file, confirm, and accept the module license.
4. Confirm SiteSync appears in the module list as **Running**.

## Next step

Import the Perspective project(s) for your edition:

- **Standard** → [Import the Perspective project](/install-upgrade/standard/import-perspective/).
- **Enterprise** → [Import Enterprise Management](/install-upgrade/enterprise/import-enterprise-management/), then the [Field App](/install-upgrade/enterprise/import-field-app/).
