## Steps

1. Open the Ignition Gateway web configuration page.
2. Go to **Config → Modules → Install or Upgrade a Module…**.
3. Select the SiteSync **Enterprise** `.modl`, confirm, and accept the license.
4. Confirm the module shows **Running**.
