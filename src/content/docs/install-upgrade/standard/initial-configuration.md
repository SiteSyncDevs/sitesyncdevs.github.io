## Steps

1. Set up your [connection](/configure/connections/add-a-connection/) — the MQTT and Join Server (API) halves. Standard supports a single connection.
2. Add a [device](/use/add-device/add-manually/) to confirm end-to-end flow.

:::tip[Optional: create a device profile]
You don't have to create a [device profile](/configure/device-profiles/create/) to get started, but doing so — with a [decoder](/configure/device-profiles/assign-decoder/) and [UDT](/configure/device-profiles/assign-udt/) assigned — lets SiteSync decode payloads and model them as tags for your first sensor type.
:::
