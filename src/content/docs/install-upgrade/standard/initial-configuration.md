## Steps

1. Set up your [connection](/configure/connections/add-a-connection/) — the MQTT and Join Server (API) halves. Standard supports a single connection.
2. Create a [device profile](/configure/device-profiles/create/) for your first sensor type, with a [decoder](/configure/device-profiles/assign-decoder/) and [UDT](/configure/device-profiles/assign-udt/) assigned.
3. Add a [device](/use/add-device/add-manually/) to confirm end-to-end flow.
