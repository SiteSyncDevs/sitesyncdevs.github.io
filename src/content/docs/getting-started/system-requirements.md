## Requirements

- An **Ignition gateway** with access to the web configuration page.
- **(Enterprise)** an Ignition **Identity Provider** with an administrator role and a general role.
- **Network access** to your LoRa Network Server API (port is network-server dependent) and to your MQTT broker (port `8883`).
- **Credentials** for network-server API access.
- **(Field App mobile)** the Ignition **Perspective mobile app** for camera QR scanning.

:::note[Confirm versions]
Add the minimum and supported **Ignition versions** (and any required Ignition modules or Java/DB requirements) per SiteSync version. Confirm with SiteSync Product — tracked in the open questions.
:::
