## Goal

Get a single-deployment SiteSync Standard install reporting data.

## Steps

1. Check [requirements](/install-upgrade/standard/requirements/).
2. [Install the module](/install-upgrade/standard/install-module/) and [import Source + the Standard project](/install-upgrade/standard/import-perspective/).
3. Add your [connection](/configure/connections/add-a-connection/) (MQTT + API).
4. Create a [device profile](/configure/device-profiles/create/) with a [decoder](/configure/device-profiles/assign-decoder/) and [UDT](/configure/device-profiles/assign-udt/).
5. Add a [device](/use/add-device/add-manually/) and [validate](/install-upgrade/standard/validate/).
