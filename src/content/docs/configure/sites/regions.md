## Purpose

Document the LoRaWAN region setting that applies to a site (for example, EU868, US915, AU915, AS923) and how it affects device behavior.

:::note[Needs input]
The Enterprise Management source doc covers Site **name** and **description** only; it does not describe a per-site region field. Confirm with SiteSync Product whether region is set at the site level, the device-profile level, or inherited from the network server, then complete this page. General region values are listed in [Supported LoRaWAN regions](/reference/supported-regions/).
:::
