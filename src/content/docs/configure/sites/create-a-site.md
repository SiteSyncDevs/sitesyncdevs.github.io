## Goal

Create a site to organize devices by location or logical grouping.

## Before you begin

:::tip[Agree on a naming convention first]
Naming conventions matter at scale. Agree on a format before you start adding sites — see [Site naming conventions](/configure/sites/naming-conventions/).
:::

## Steps

1. In the left sidebar, select **Sites**.
2. Select **Add site** in the top-right corner.
3. Fill in the site details (see fields below).
4. Select **Save**. The site is immediately available and appears in your Sites list.

## Fields

| Field | Required | Description |
| --- | --- | --- |
| Site name | Yes | A unique, human-readable name for the site. |
| Description | No | Free-text notes about the site. |

## Expected result

The site appears in your Sites list and is available immediately. New devices can be assigned to it, and a matching device folder is created.

## Verify

1. Open **Sites** and confirm the new site is listed.
2. Open the site to confirm its details.
