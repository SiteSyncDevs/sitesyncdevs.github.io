## Goal

Update a site's name or description.

## Steps

1. In the left sidebar, select **Sites**.
2. Find the site to edit and select its name to open the site detail page.
3. Select **Edit site** (top-right of the site detail page).
4. Make your changes and select **Save**.

## Expected result

Changes take effect immediately and are visible to all users with access to that site.
